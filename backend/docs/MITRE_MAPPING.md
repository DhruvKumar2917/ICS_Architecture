# MITRE ATT&CK Mapping Subsystem Documentation
## Context-Aware Mapping & Multi-Agent LLM Pipeline

This document details the architecture, algorithms, implementation, and correctness standards of the MITRE ATT&CK Mapping Subsystem.

---

## 1. What is Done
The MITRE Mapping Subsystem implements:
- **Context-Aware Mapper**: Gathers metadata from graph nodes.
- **Rule-Based Mapping Mode**: Evaluates transitions using a deterministic rule matrix.
- **Multi-Agent LLM Mapping Mode**: Coordinates an 8-agent reasoning chain with a self-correcting feedback loop.
- **Confidence Calibration Engine**: Dynamically calculates and refines confidence scores.
- **Graph Reachability Validator**: Verifies network paths and zone-conduit configurations.

### 2.2 Multi-Agent Logic & Confidence Calibration

#### 2.2.1 The 8-Agent Pipeline
1. **Context Builder**: Gathers and enriches edge metadata.
2. **Candidate Selection**: Filters the ATT&CK catalog to generate a shortlist of compatible techniques based on asset type and protocol.
3. **Attack Chain Reasoning**: Determines the attacker's progression stage (e.g. Initial Access, Discovery, Lateral Movement, Impair Process Control).
4. **MITRE Reasoning**: Prompts the LLM to select the most appropriate technique from the shortlist.
5. **Semantic Validation**: Evaluates the LLM's response, checking for name-to-ID mismatches, inconsistent reasoning, and improper tactic classifications.
6. **KB Verification**: Audits the selected technique against the official ATT&CK catalog.
7. **Graph Consistency**: Ensures that the sequence of tactics along an attack path follows a logical progression.
8. **Confidence Calibration**: Adjusts the confidence score.

#### 2.2.2 Confidence Calibration math
The baseline confidence score is adjusted dynamically:
- **Firewall Adjustment**: If the firewall blocks the connection (`Firewall = Denied`), the action is flagged as unsuccessful and the confidence score is capped at `0.40`.
- **Reachability Adjustment**: If the target node is unreachable (`Reachable = No`), the confidence score is capped at `0.30`.
- **Ontology Verification**: If the protocol and asset type match the official MITRE ATT&CK specifications, the confidence score is increased by `10%`.

## 3. Correctness Standards & Validation

To ensure mapping accuracy, the platform enforces the following correctness criteria:
1. **Shortlist Enforcement**: The chosen technique must reside in the candidate shortlist generated by the Candidate Selection Agent.
2. **Tactic Alignment**: The selected tactic must match the official tactic classification of the technique in the ATT&CK database.
3. **Self-Correction Feedback Loop**: If semantic validation fails, the engine automatically retries up to 3 times, passing the error messages back to the LLM.
4. **Graph Consistency Validation**: Validates that tactic progression along an attack path follows a logical, sequential flow (no Initial Access tactics occurring after Impair Process Control).
